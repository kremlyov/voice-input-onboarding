# Онбординг голосового ввода

Анимированный прототип для обсуждения с разработчиками.

Демонстрация запускается автоматически, последовательно показывает замену слова, удаление фразы и добавление эмодзи. В финале анимация останавливается. Под экраном телефона доступна кнопка «Повторить»; элементы внутри макета не выполняют действий.

Продолжительность: около 19 секунд. Все ресурсы встроены в `index.html`: его можно открыть в браузере без установки и подключения к интернету.

Тайминги находятся в блоке `TIMING`, длительности анимаций — в стилях этого же файла.
