# Онбординг голосового ввода

Анимированный прототип для обсуждения с разработчиками.

Демонстрация запускается автоматически, последовательно показывает замену слова, удаление фразы и добавление эмодзи. В финале текст замирает. Под экраном телефона доступна кнопка «Повторить»; элементы внутри макета не выполняют действий.

Точечный фон состоит из векторных SVG-кружков диаметром 2,2 px с непрозрачностью 60%. Точки сохраняют круглую форму и плавно движутся волной с циклом 14 секунд, включая финальный экран. Осветление в центре остаётся неподвижным. Движение фона приостанавливается в скрытой вкладке и отключается при настройке уменьшения движения.

Продолжительность: около 19 секунд. Все ресурсы встроены в `index.html`: его можно открыть в браузере без установки и подключения к интернету.

Тайминги находятся в блоке `TIMING`, параметры фоновой волны — в `DOTS`, длительности переходов текста — в стилях этого же файла.
